# Опыты

Численные и символьные проверки гипотез. Опыт создаётся командой
`python scripts/state/proj.py new experiment "Название" --idea I07` и лежит в своей папке `E*/`:
`run.py` с зависимостями в заголовке (PEP 723) и `README.md` с вопросом, командой запуска,
проверкой метода и результатом.

- Опыт запускается одной командой: `uv run experiments/E01/run.py`. Параметры и зерно
  случайных чисел записаны в коде.
- До основного расчёта метод проверяется на контрольном случае из `question.md`, где
  ответ известен; расхождение записывается.
- Результат приводится с оценкой погрешности: не меньше трёх разрешений или двух
  независимых методов.
- Вывод опыта — «согласуется с гипотезой» или «не согласуется». Доказательством опыт не
  служит и статус записи не меняет.
- Рисунки и большие таблицы пишутся в `output/experiments/`; код и итоговые числа — здесь.
