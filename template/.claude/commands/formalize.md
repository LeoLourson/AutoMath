---
description: Формализация записи в Lean и проверка соответствия
---

Формализуй запись: $ARGUMENTS

Аргумент — номер `R…`. Запуск команды — прямой запрос пользователя на запуск агентов.

## 1. Готовность

- В записи точная формулировка. Лучше всего — статус «доказано» с принятой рецензией.
  Утверждение без бумажного доказательства формализовать можно, но в отчёте это названо.
- Записи из `depends`: у формализованных есть имена Lean; про остальные скажи, что их
  придётся доказывать по пути.

## 2. Формализатор

Запусти агента `formalizer`: номер записи и объявления Lean её зависимостей. По итогу:

- `остановлено на формулировке` — расхождение решает пользователь. Не продолжай: вынеси
  в отчёт формулировку Lean, перечень расхождений и предложение агента.
- `остановлено на лемме` — заготовка лежит в `output/drafts/`. Один раз можно вернуть
  лемму формализатору с новой подсказкой. Отправка в Aristotle — только по прямому
  запросу пользователя.
- `доказано более слабое` — поле `lean` записи этим именем не заполняется. Заведи для
  доказанного утверждения отдельную запись.
- `доказано` — переходи к приёмке.

## 3. Приёмка

1. `lake build`; `python scripts/proj.py set R07 lean "Полное.Имя, Другое.Имя"`;
   `python scripts/proj.py audit R07`.
2. Запусти агента `fidelity-checker` и передай ему номер записи. Отчёт формализатора ему
   не передавай.
3. Проверь, что раздел «Соответствие формализации» записан в файл. Затем
   `python scripts/proj.py set R07 fidelity "ГГГГ-ММ-ДД вердикт ОТПЕЧАТОК"`; отпечаток из
   отчёта стоит последним словом.
   - `соответствует с оговорками`: впиши оговорки в раздел «Границы» записи.
   - `не соответствует`: очисти поле `lean` (значение — пустая строка), теорему оставь в
     библиотеке под её именем и заведи запись о том, что доказано на самом деле. Вопрос
     о правильной формулировке вынеси пользователю.

## 4. Итог

`python scripts/proj.py sync`, затем `python scripts/proj.py check`. Отчёт: объявления;
вердикт соответствия; новые определения, которые ждут решения пользователя; что не
доказано и где лежит заготовка.
