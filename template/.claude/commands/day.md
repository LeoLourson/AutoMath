Выполни ежедневный цикл. Правила — `AGENTS.md` и `PROJECT.md`; здесь порядок шагов.
Аргумент — пожелание на сегодня (цель, идея, ограничение по времени): $ARGUMENTS

Цикл идёт без вопросов к пользователю. Решения, которые принимает только он, собираются
в конце отчёта. Коммитов цикл не делает. Запуск `/day` — прямой запрос пользователя на
запуск агентов.

## 1. Состояние

1. `git status --short` и `git log -3 --oneline`. Незакоммиченные изменения прошлого дня
   назови в отчёте.
2. `python scripts/proj.py check`. Ошибки чинятся до новых целей. Замечания выпиши: из
   них берётся работа дня — записи без рецензии, непроверенное или устаревшее
   соответствие, источники без карточек, идеи без критики.
3. Прочитай `question.md`, `blueprint.md`, `ideas/README.md`. Записи и идеи открывай
   целиком только те, с которыми будешь работать.

## 2. Идеи

Выполни шаги команды `/ideas` (`.claude/commands/ideas.md`) для одной-трёх целей: цель из
пожелания, затем открытые вопросы без идей в работе.

## 3. Цель дня

Одна цель, по убыванию предпочтения:

1. запись с принятой рецензией без Lean — формализация;
2. запись «доказано» без рецензии — рецензия, затем формализация, если останется время;
3. идея, выдержавшая критику, — полное доказательство в новой записи;
4. замечания проверки: устаревшее соответствие, источник без карточки.

Если подходящей цели нет, день уходит на идеи и источники; так и напиши.

## 4. Работа над целью

- **Доказательство.** Создай запись: `python scripts/proj.py new result "Название"
  --depends R03,R05`. Запиши утверждение, полное доказательство и границы; поставь статус
  `доказано`; идее поставь статус `перенесена` и поле `result`. Затем выполни шаги
  команды `/referee`.
- **Формализация.** Шаги команды `/formalize`.
- **Источник.** Шаг 4 команды `/sources`.

Новое определение, от которого зависит смысл итоговой теоремы, и любое изменение
постановки выносятся в отчёт; работа, которая от них зависит, ждёт решения пользователя.

## 5. Aristotle

Шаг выполняется, только если пользователь попросил об этом в пожелании или в разделе
«Особые правила» файла `PROJECT.md`. Заготовку с `sorry` для самой трудоёмкой леммы дня
упакуй командой `python scripts/proj.py aristotle pack ИМЯ output/drafts/Лемма.lean`,
допиши `prompt.md` и отправь. Готовые ответы прошлых дней прими:
`python scripts/proj.py aristotle accept ИМЯ АРХИВ`, затем перенос модуля, `lake build`
и шаг 3 команды `/formalize`.

## 6. Завершение

1. `python scripts/proj.py sync`, `python scripts/proj.py check`. Если менялись файлы в
   `scripts/`, ещё `python -m unittest discover tests`.
2. Раздел «Ответ на …» в `question.md` обнови, если изменился ответ на вопрос. Статусы в
   нём не повторяются.
3. Если результат дня меняет ответ статьи, напиши в отчёте, что пора запустить
   `/exposition`.

## 7. Отчёт

- что доказано и формализовано: записи и объявления Lean;
- рецензии и проверки соответствия с вердиктами;
- идеи: новые, отвергнутые, выдержавшие критику — по строке;
- проверки: что прошло и какие замечания остались;
- открытые вопросы и цели;
- решения за пользователем и предложенное сообщение коммита.
