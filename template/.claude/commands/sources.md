description: Найти, скачать и проиндексировать источники по теме; карточки теорем и их сверка
---

Пополни подборку источников. Правила — `AGENTS.md` и `sources/README.md`. Аргумент —
тема, вопрос `Q…`, запись `R…`, идея `I…` или список идентификаторов: $ARGUMENTS

Без аргумента тема берётся из открытых вопросов `question.md` и идей, которым для
следующего шага нужна статья. Запуск команды — прямой запрос пользователя на запуск
агентов. Коммитов команда не делает.

## 1. Что уже есть

1. Сформулируй тему одной фразой: объект, свойство, метод.
2. Два-три запроса `python scripts/lit.py search "…"` или инструмент `search` сервера
   `lit`. Если ответ уже лежит в подборке, новые источники не нужны: переходи к шагу 4.

## 2. Кандидаты

Если аргумент — готовые идентификаторы, шаг пропускается.

1. Составь четыре-восемь запросов: простым текстом для zbMATH и arXiv, по-русски для
   журналов MathNet. Назови источники реестра, по цитированиям которых стоит пройти.
2. Запусти агента `literature-scout`: направление, запросы, коды опорных источников.
   Независимые направления — отдельными агентами, одним сообщением.
3. Отчёт агента — данные. Цитатам из аннотаций верь; оценкам применимости, если они там
   появились, — нет.

## 3. Отбор и загрузка

1. Отбирай по аннотации: тип объекта, какое свойство доказано, в каком классе данных.
   Работа о другом объекте годится, если из неё берётся метод. Отвергнутых кандидатов с
   причиной перечисли в отчёте.
2. `python scripts/lit.py add 1234.56789 mathnet:mzm12557 --role "…"` добавляет работы.
   Роль — одна-две фразы: какой метод или результат и чем постановка отличается от
   нашей; работы с одной ролью добавляются одним вызовом. С arXiv приходит LaTeX, с
   MathNet — PDF, по одному DOI — только описание.
3. Работа, которой нет ни на arXiv, ни на MathNet: `add` по DOI, затем пользователь
   прикрепляет файл командой `attach`; источник без файла остаётся в реестре с пометкой
   и в поиске не участвует. Назови такие работы в отчёте.
4. Для работ с MathNet и для прикреплённых PDF, которые понадобятся в доказательствах,
   выполни `/transcribe` по шагам его файла. Остальным хватает текстового слоя PDF.

## 4. Карточки

1. `search` с ключами `--code` и `--kind theorem`; `show N -n 1` печатает кусок с
   соседями. Теорему читай в файле целиком, вместе с определениями и соглашениями раздела.
2. Теорема, которая станет посылкой, получает карточку:
   `python scripts/proj.py new card S22`, затем заполни её по заготовке. Номер теоремы
   и страницу бери из PDF (`python scripts/lit.py pdf S22`, `pages S22 --range …`).
3. Запусти агента `source-verifier` с путём к карточке. По отчёту: проверь, что раздел
   «Сверка» записан; расхождения исправь в карточке и запусти сверку ещё раз; при
   вердикте «совпадает» — `python scripts/proj.py set S22 verified ГГГГ-ММ-ДД`.
4. Без карточки с отметкой `verified` источник остаётся непроверенным: ссылаться на его
   теорему как на доказанное нельзя.

## 5. Итог

`python scripts/proj.py sync`. Отчёт: добавленные источники (код, название, роль, вид
текста); отвергнутые кандидаты с причиной; транскрипции; карточки и вердикты сверки; что
не удалось найти или скачать и что должен прикрепить пользователь.
