Проверь соответствие формализации: $ARGUMENTS

Аргумент — номер записи. Без аргумента берутся все записи, о которых
`python scripts/proj.py check --fast` сообщает «соответствие формализации не проверено»
или «изменились после проверки соответствия». Запуск команды — прямой запрос
пользователя на запуск агентов.

1. Для каждой записи запусти агента `fidelity-checker` и передай ему только номер записи.
   Одновременно — не больше четырёх.
2. Проверь, что раздел «Соответствие формализации» записан, и перенеси вердикт:
   `python scripts/proj.py set R07 fidelity "ГГГГ-ММ-ДД вердикт ОТПЕЧАТОК"`. Оговорки
   впиши в «Границы»; при вердикте «не соответствует» поступи по шагу 3 команды
   `/formalize`.
3. Если проверка повторная, сравни новый раздел с прежним. Изменение смысла формулировки
   назови в отчёте отдельно.
4. `python scripts/proj.py sync`, `python scripts/proj.py check --fast`. Отчёт: по строке
   на запись — объявления, вердикт, расхождения.
