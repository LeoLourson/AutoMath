# 23. Ограничения анализа

## 23.1. Корпус

- 28 файлов, из них 19 в соавторстве;
- индивидуальный вклад соавторов не всегда отделим;
- 9 односоставных текстов используются как наиболее надёжное ядро;
- даты присутствуют не во всех файлах.

## 23.2. Состояние файлов

Корпус является распознанным:

- встречаются ошибки кириллицы;
- встречаются полноширинные знаки в английском тексте;
- отсутствуют авторские `\newtheorem` и `\bibitem`;
- часть формул могла быть повреждена при распознавании.

Поэтому:

1. количественные подсчёты слов и окружений надёжны;
2. выводы об авторских LaTeX-макросах невозможны;
3. выводы о типографике частично относятся к журнальной вёрстке, а не к автору.

## 23.3. Какие выводы устойчивы

К устойчивым относятся:

1. начало с объекта или напоминания;
2. инфинитивная цель;
3. трёхтактная схема теоремы;
4. условия `(i)`–`(iii)`;
5. шаги доказательства;
6. словесные концовки доказательств;
7. экономия нумерации формул;
8. адресные ссылки;
9. финал-граница;
10. отсутствие заключения.

## 23.4. Какие выводы предварительны

1. распределение рангов между леммой и предложением;
2. типографика капители и курсива;
3. порядок списка литературы;
4. редкость доказательств от противного;
5. авторские LaTeX-окружения.


# 24. Рекомендации по дополнению корпуса

Для более надёжного анализа желательно добавить:

1. 2–3 одноавторские работы 1983–1992 гг., чтобы закрыть ранний период.
2. Авторские LaTeX-исходники, если они существуют.
3. Английские исследовательские статьи полного объёма, а не только анонсы.
4. Рецензии, предисловия, редакторские заметки.
5. Лекции или учебные пособия в полном виде.
6. Тексты с рисунками и диаграммами, чтобы проверить, является ли [Ст. 11] исключением.
7. Работы с явными алгоритмами или коммутативными диаграммами, если такие есть.

Минимальный объём для надёжного анализа каждого аспекта:

- для макроструктуры: 10–12 текстов одного жанра;
- для эволюции стиля: минимум 3 текста на каждое десятилетие;
- для LaTeX-выводов: хотя бы 3–5 подлинных авторских исходников;
- для английских клише: минимум 3 английские исследовательские статьи.


# 25. Как использовать этот мануал

## 25.1. Для написания новой статьи

1. Взять шаблон архитектуры из раздела 4.
2. Заполнить аннотацию по шаблону раздела 5.
3. Написать введение по каркасу раздела 6.
4. Определения строить по разделу 8.
5. Теоремы формулировать по разделу 9.
6. Доказательства писать по разделу 10.
7. Формулы оформлять по разделу 11 и 16.
8. Перед отправкой прогнать текст по чеклисту раздела 21.

## 25.2. Для редактирования существующего текста

Проверить:

1. начинается ли введение с объекта;
2. есть ли цель инфинитивом;
3. есть ли историческая справка;
4. есть ли пробел;
5. анонсирован ли главный результат;
6. нет ли заключения;
7. закрыты ли доказательства словесными формулами;
8. нумеруются ли только цитируемые формулы.

## 25.3. Для рецензирования в стиле автора

Рецензия должна быть:

- точечной;
- без общих слов о важности;
- с указанием конкретного места, где отсутствует аргумент;
- с конструктивным предложением исправления;
- без личных оценок.

Шаблон замечания:

```текст
В разделе [N] определение [ТЕРМИН] не согласовано с классическим случаем.
Не указано, что при [УСЛОВИЕ] оно переходит в [КЛАССИЧЕСКОЕ ОПРЕДЕЛЕНИЕ].
Следует добавить соответствующую проверку.
```

## 25.4. Для обучения студентов

Студенту полезно показать:

1. как автор вводит определение через «назовём»;
2. как строится двухступенчатая шкала классов;
3. как формулируется цель;
4. как доказательство разбивается на шаги;
5. как оформляется словарь замен при аналогии;
6. как статья заканчивается границей, а не общим выводом.

## 25.5. Для автоматической проверки соответствия стилю

Минимальный автоматический набор маркеров:

- наличие «Напомним»;
- наличие «Цель работы» / «Основная цель»;
- наличие «Однако»;
- наличие «назовём» / «Будем говорить»;
- наличие «Более того»;
- наличие «Шаг» / `Step`;
- наличие «Теорема доказана» / «Лемма доказана»;
- отсутствие «Заключение» / `Conclusion`;
- отсутствие буллитов;
- отсутствие `to the best of our knowledge`.


# 26. Итоговое ядро стиля

Если сжать все наблюдения до минимального воспроизводимого ядра, стиль А. А. Шкаликова определяется следующими семью принципами:

1. **Сначала объект.**  
   Текст начинается с формулы, определения или напоминания, а не с общих слов.

2. **История как объяснение.**  
   История вопроса нужна не для вежливости, а чтобы показать, почему текущий результат необходим.

3. **Новизна через зазор.**  
   Автор не кричит о новизне, а показывает, какие именно условия или случаи не были покрыты.

4. **Определения как лестница.**  
   Классы вводятся ступенями: базовый класс, усиленный класс, предельные случаи.

5. **Доказательство как управляемый процесс.**  
   Длинные аргументы разбиваются на шаги, планы объявляются, аналогии сопровождаются словарём замен.

6. **Экономия на стандартном.**  
   Стандартное не повторяется, но всегда указывается, где именно оно уже доказано.

7. **Финал как граница.**  
   Статья заканчивается не риторическим итогом, а указанием границы: что ослабляется, что расширяется, что остаётся нерешённым.
