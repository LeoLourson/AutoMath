# 7. Шаблон раздела предварительных сведений

Отдельный `Preliminaries` у автора обычно не выделяется. Его функцию выполняют:

- второй-третий абзац введения;
- раздел «Вспомогательные результаты»;
- рубрики в подбор;
- определения и соглашения внутри §1.

## 7.1. Ввод обозначений

Устойчивые формулы:

- «Обозначим через…» — 51 вхождение в 18 файлах [по 28-файловому корпусу];
- «Положим…» — 74 вхождения в 19 файлах;
- «Пусть…» — основной ввод допущений;
- «Через \(\sigma(A)\) и \(\rho(A)\) далее обозначаем спектр и резольвентное множество оператора \(A\).» [Ст. 23 / ручной мануал].

## 7.2. Сквозные соглашения

Устойчивые формулы:

```текст
Всюду далее в работе, где не возникает недоразумений,
вместо [ПОЛНАЯ ЗАПИСЬ] будем писать [КОРОТКАЯ ЗАПИСЬ].
```

```текст
Здесь и далее [ОБОЗНАЧЕНИЕ] означает [СМЫСЛ].
```

Примеры:

- «Всюду далее … вместо \(\mu I\) … будем писать просто \(\mu\).» [Ст. 23];
- «Здесь и далее через \(M\) обозначаются различные положительные константы…» [Ст. 28];
- «Здесь и далее “п.в.” означает “почти для всех”.» [Ст. 15 / ручной мануал].

## 7.3. Напоминание известных фактов

Формулы:

```текст
Напомним, что [ОПРЕДЕЛЕНИЕ / ФАКТ].
```

```текст
Известно [n, гл. K, § M], что [ФАКТ].
```

```текст
Хорошо известно (см., например, [n]), что [ФАКТ].
```

## 7.4. Предупреждение о близких обозначениях

```текст
Обратим внимание, что далее [A] и [B] имеют разный смысл.
А именно, [A] обозначает [СМЫСЛ 1], а [B] — [СМЫСЛ 2].
```

Пример: различение \(L(y)\) и \(Ly\) [Ст. 25 / ручной мануал §6.2].


# 8. Шаблоны определений

## 8.1. Тип A. Центральное понятие через «назовём»

```текст
Определение [N]. [ОБЪЕКТ В ВИНИТЕЛЬНОМ ПАДЕЖЕ] назовём [ТЕРМИНОМ],
если [УСЛОВИЕ].
```

Примеры:

- «Краевую задачу (0.1), (0.2) назовём регулярной, если…» [Ст. 18];
- «Спектральную задачу (1), (2) назовём регулярной, если…» [Ст. 7].

## 8.2. Тип B. Двухступенчатое определение с усилением

```текст
[ОБЪЕКТ] назовём [КЛАСС], если [УСЛОВИЕ].
[КЛАСС] назовём [УСИЛЕННЫЙ КЛАСС], если дополнительно [УСИЛЕНИЕ].
```

Примеры:

- регулярный → сильно регулярный [Ст. 7];
- регулярный → вполне регулярный [Ст. 6];
- regular → almost regular / normal / degenerate [Ст. 9].

## 8.3. Тип C. «Будем говорить, что…»

```текст
Будем говорить, что [ОБЛАСТЬ / ОБЪЕКТ] обладает [СВОЙСТВОМ]
(или выполнено условие [ИМЯ]), если [ФОРМУЛА / УСЛОВИЕ].
```

Примеры:

- условие Биркгофа [Ст. 15];
- класс \(K_\alpha\) [Ст. 4 / ручной мануал §7.2].

## 8.4. Тип D. Определение через список

```текст
Определение [N]. [ОБЪЕКТ] назовём [ТЕРМИНОМ], если выполнены следующие условия:
а) [УСЛОВИЕ 1];
б) [УСЛОВИЕ 2];
в) [УСЛОВИЕ 3].
```

Пример: определения эллиптического пучка [Ст. 5 / ручной мануал §7.3].

## 8.5. Тип E. Служебное определение курсивом внутри абзаца

```текст
[ОБЪЕКТ] называется [ТЕРМИНОМ], если [УСЛОВИЕ].
[ОБЪЕКТ] называется [УСИЛЕННЫЙ ТЕРМИНОМ], если он не допускает [ОГРАНИЧЕНИЕ].
```

Примеры:

- диссипативный и максимально диссипативный оператор [Ст. 23];
- \(T\)-подчинённый оператор [Ст. 4].

## 8.6. Мотивировка определения

Перед определением желательно дать мотивировку:

```текст
Мы будем исходить из другого более короткого и информативного определения,
с помощью которого значительно упрощаются технические приёмы в доказательствах.
```

[Ст. 7]

После определения желательно дать проверку согласованности:

```текст
Заметим, что при [СТАРОЕ УСЛОВИЕ] определение совпадает с классическим,
так как [ПРИЧИНА].
```

[Ст. 22, Ст. 3]
