# 11. Шаблоны вычислений, оценок и формул

## 11.1. Ввод формулы

Типовые связки:

- «имеем»;
- «получаем»;
- «Положим»;
- «Тогда»;
- «Рассмотрим»;
- «Обозначим через».

Характерная рамка:

```текст
Переходя к пределу при [ПАРАМЕТР] и учитывая неравенство
[ФОРМУЛА],
получаем
[ФОРМУЛА].
```

[Ст. 23 / ручной мануал §10.2]

## 11.2. Пунктуация вокруг формул

Формула является членом предложения:

```текст
[ФОРМУЛА],
где [РАСШИФРОВКА].
```

или:

```текст
[ФОРМУЛА].
При этом [НОВОЕ ПРЕДЛОЖЕНИЕ].
```

Нельзя начинать предложение с формулы.

## 11.3. Нумерация формул

Устойчивое правило:

> нумеруются только те формулы, на которые есть ссылка.

По 28-файловому корпусу:

- 1294 нумерованные формулы;
- 3607 выключных формул;
- номер получает примерно каждая четвёртая выключная формула.

## 11.4. Константы

Шаблоны:

```текст
… ⩽ C |α|^{-1} при [ОБЛАСТЬ ПАРАМЕТРА]
с постоянной C, не зависящей от [ПАРАМЕТР].
```

```текст
где константа зависит только от [СПИСОК ПАРАМЕТРОВ].
```

```текст
Здесь и далее через M обозначаются различные положительные константы.
```

# 16. Правила оформления формул

## 16.1. Встроенные и выключные формулы

Встроенные формулы используются для коротких соотношений:

```текст
выполнено неравенство [x,x] ≥ 0
```

Выключные формулы используются для:

1. нумеруемых соотношений;
2. длинных выражений;
3. определений объекта;
4. матриц и систем.

## 16.2. Нумерация

Правило:

> Номер получает только формула, на которую будет ссылка.

Схемы:

- сквозная `(1)`, `(2)` — короткие и средние тексты;
- посекционная `(1.4)`, `(2.7)` — крупные тексты;
- смешанная: теоремы сквозные, формулы посекционные — встречается [ручной мануал §8.2].

## 16.3. Пунктуация

Формула — часть предложения. После неё:

- запятая, если дальше идёт придаточное или «где»;
- точка, если дальше новое предложение.

Пример шаблона:

```текст
[ФОРМУЛА],
где [РАСШИФРОВКА], причём [СВОЙСТВО].
```

или:

```текст
[ФОРМУЛА].
При этом [СВОЙСТВО].
```

## 16.4. Условия под операторами

Стиль автора — явно указывать пределы и области:

```текст
при λ → ∞ в секторе Γ
равномерно по x ∈ [0,1]
при k → ±∞
```
