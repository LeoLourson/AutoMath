# 15, 19. Как набраны работы автора: обозначения и каркас

Справка о привычках автора. Набор файла, который правится, определяют слой набора
(`math-typeset`) и преамбула этого файла; обозначения — уже введённые в нём. Буквы и
интервалы из таблиц ниже относятся к задачам автора; в статье о другом объекте
обозначения выбираются по её постановке.

## 15. Обозначения

Словарь неполон: он фиксирует устойчивые роли символов.

### 15.1. Пространства

| Объект | Обозначение | Типовая фраза |
|---|---|---|
| Гильбертово пространство | $H$ | «Пусть $H$ — гильбертово пространство» |
| Разложение по знаку метрики | $H=H_+\oplus H_-$ | «Представим пространство $H$ в виде ортогональной суммы…» |
| Пространство Понтрягина | $\Pi_\kappa$ | «называют пространством Понтрягина и обозначают $\Pi_\kappa$» |
| Лебеговы пространства | $L_2[a,b]$, $L_1[0,1]$, $L_p$ | стандартно |
| Соболевские пространства | $W_p^k[0,1]$ | «Здесь и далее $W_p^k[0,1]$ — пространства Соболева» |
| Область определения | $D(A)$, иногда $\mathcal D(L)$, $\mathscr D(T)$ | «с областью определения $D(A)$» |
| Шкала пространств | $H_\theta=D(T^{\theta/2})$ | [Ст. 21, Ст. 20] |

### 15.2. Операторы

| Роль | Буква | Комментарий |
|---|---|---|
| Главный дифференциальный оператор | $L$ | статьи о краевых задачах |
| Абстрактный оператор | $A$, $T$ | операторные статьи |
| Невозмущённый оператор | $T$ | в задачах $A=T+B$ |
| Возмущение | $B$ | там же |
| Инволюция, симметрия | $J$ | в работах автора $Jy(x)=y(-x)$ |
| Проекторы | $P_+$, $P_-$ | разложение пространства |
| Угловой оператор | $K$ | представление подпространства |
| Блоки матрицы | $A_{11}$, $A_{12}$, $A_{21}$, $A_{22}$ | блочные операторы |
| Функция Шура | $S(\mu)$ | $S(\mu)=A_{11}-A_{12}(A_{22}-\mu)^{-1}A_{21}$ |
| Пучок | $L(\lambda)=\lambda^2+\lambda A+C$ | квадратичные пучки |

### 15.3. Матрицы и системы ОДУ

| Объект | Обозначение | Комментарий |
|---|---|---|
| Диагональная главная часть | $A(x)=\operatorname{diag}\lbrace a_j(x)\rbrace$ или $B(x)$ | буквы меняются от статьи к статье |
| Младшая матрица | $B(x)=\lbrace b_{jk}(x)\rbrace$ или $A(x)=\lbrace a_{jk}(x)\rbrace$ | зависит от статьи |
| Малое возмущение | $C(x,\lambda)$ | $\lVert c_{jk}\rVert\to0$ |
| Экспоненциальная матрица | $E(x,\lambda)$ | диагональные экспоненты |
| Матрица нормировки | $M(x)$ | экспоненциальные множители |
| Фундаментальная матрица | $Y(x,\lambda)$ | основной объект асимптотики |
| Остаток | $R(x,\lambda)$ | $\lvert R\rvert\to0$ |
| Характеристический определитель | $\Delta(\lambda)$, $\Delta(\rho)$ | регулярность |

### 15.4. Параметры и постоянные

| Роль | Обозначение | Правило |
|---|---|---|
| Спектральный параметр | $\lambda$ | почти всегда |
| Корень | $\rho$, $\lambda=\rho^n$ | в задачах высших порядков |
| Точка резольвентного множества | $\mu$ | в формулах с резольвентой |
| Раствор сектора | $\alpha$, $\theta$ | секторы комплексной плоскости |
| Малые положительные | $\varepsilon$, $\delta$ | оценки и разделения |
| Постоянные | $C$, $C_1$, $C_2$, $M$, $\mathrm{const}$ | зависимость оговаривается явно |

### 15.5. Асимптотические и служебные символы

- $o(1)$, $O(\lambda^{-2})$;
- $\to$ — обычная сходимость;
- $\Rightarrow$ — сходимость по норме;
- $\rightharpoonup$ — слабая сходимость;
- $\equiv$ — тождественно;
- $:=$ — определяющее равенство;
- «п.в.» — почти всюду.

## 19. Каркас документа

### 19.1. Оговорка

В корпусе нет авторских `\newtheorem` и `\bibitem`: тексты получены распознаванием
печатных страниц. Поэтому каркас ниже — реконструкция по печатной структуре статей и
журнальным конвенциям; что из него выбор автора, а что журнала, по корпусу не различить.
Выводы об авторских окружениях предварительны.

### 19.2. Как выглядит печатная статья автора

- Утверждения называются «Теорема», «Лемма», «Предложение», «Следствие», «Определение»,
  «Замечание». Типографика заголовков (капитель, курсив) по корпусу установлена
  предварительно: она может принадлежать журналу.
- Нумерация: в крупных статьях теоремы и формулы нумеруются по разделам, в коротких и
  средних — подряд; встречается смешанная система.
- Доказательство открывает слово «Доказательство.»; шаги выделены словами «Шаг 1.»,
  «Шаг 2.».
- Словесная концовка («Теорема доказана.») стоит последней фразой доказательства. Знак
  $\square$ в корпусе встречается, но в крупных русских текстах словесную форму не
  вытесняет.
- Ссылки на литературу числовые, `[n]`; порядок списка литературы установлен
  предварительно.

Реконструкция этих привычек средствами LaTeX. В готовом файле ничего из неё не вводится:
окружения, счётчики и вид конца доказательства берутся из его преамбулы.

```latex
% нумерация по разделам, как в крупных статьях автора
\theoremstyle{plain}
\newtheorem{theorem}{Теорема}[section]
\newtheorem{lemma}[theorem]{Лемма}
\newtheorem{proposition}[theorem]{Предложение}
\newtheorem{corollary}[theorem]{Следствие}
\theoremstyle{definition}
\newtheorem{definition}[theorem]{Определение}
\theoremstyle{remark}
\newtheorem{remark}[theorem]{Замечание}
\numberwithin{equation}{section}

% сквозная нумерация, как в коротких статьях
% \newtheorem{theorem}{Теорема}
% \newtheorem{lemma}{Лемма}
% \newtheorem{proposition}{Предложение}
```

Привычка автора, расходящаяся с обычным набором: словесная концовка внутри
доказательства. В окружении `proof` пакета `amsthm` после неё встанет ещё и знак конца
доказательства; будет ли он виден, решает преамбула файла.

```latex
\begin{proof}
Доказательство разобьем на несколько шагов.

\smallskip\noindent\textbf{Шаг 1.} \ldots

\smallskip\noindent\textbf{Шаг 2.} \ldots

Теорема доказана.
\end{proof}
```

Порядок разделов печатной статьи описан в `02-architecture.md`.
