# 17. Правила ссылок и цитирования

## 17.1. Внешние ссылки

Основная форма — числовые ссылки `[n]`.

Устойчивая авторская черта: ссылка на факт почти никогда не бывает «голой».

Хорошо:

```текст
Известно [12, гл. 2, теорема 2.9], что …
```

```текст
см. подробности в [2, §4]
```

Плохо в стиле автора:

```текст
Известно [12], что …
```

если факт требует точного адреса.

## 17.2. Внутренние ссылки

На свои утверждения — строчными:

```текст
в силу леммы 5
согласно предложению 1
из теоремы 3 получаем
```

На формулы:

```текст
из (12)
в силу (3.4)
согласно (2.7)
```

На разделы:

```текст
в §2
в п. 2.3
```

## 17.3. Признание приоритета

Чужие результаты называются по именам:

- теорема Понтрягина;
- теорема Лангера;
- теорема Крейна–Лангера–Азизова;
- теорема Лидского.

Пример:

- [Ст. 23]: «Полученная теорема является обобщением ранее известных результатов Л. С. Понтрягина, Г. К. Лангера, М. Г. Крейна и Т. Я. Азизова…»

## 17.4. Критика

Если критика необходима, она должна быть точечной:

```текст
В работе [n] дано другое определение, которое не совпадает с нашим.
Трудно понять причину несоответствия, так как в [n] не приводятся аргументы.
В любом случае, определение [n] подлежит коррекции.
```
