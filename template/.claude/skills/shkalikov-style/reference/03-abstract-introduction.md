# 5. Шаблон аннотации

## 5.1. Наблюдаемые параметры

По ручному мануалу:

- объём: 45–110 слов;
- медиана: около 65 слов;
- структура из четырёх тактов:
  1. объект;
  2. условия;
  3. что доказано;
  4. отношение к предшественникам.

Такта «значение результата для науки» обычно нет.

## 5.2. Типовые начала

- «Рассматривается…» [ручной мануал, аннотации];
- «В статье изучается…» [ручной мануал, аннотации];
- «Let P and Q be…» [Ст. 8 / английский анонс];
- «Our main result is as follows:…» [Ст. 12].

## 5.3. Типовые завершения

- «Полученная теорема является обобщением ранее известных результатов…» [Ст. 23];
- «Теоремы, доказанные в работе, дополняют и обобщают результаты классической теории…» [ручной мануал, Ст. 13];
- «Библиография: 89 названий.» [Ст. 4].

## 5.4. Заполняемый шаблон аннотации

```текст
Рассматривается [ОБЪЕКТ], порождённый [УРАВНЕНИЕМ / ОПЕРАТОРНЫМ ВЫРАЖЕНИЕМ]
[ФОРМУЛА или его описание]
при условиях [УСЛОВИЯ НА КОЭФФИЦИЕНТЫ / КРАЕВЫЕ УСЛОВИЯ].
Здесь [РАСШИФРОВКА ОБОЗНАЧЕНИЙ].

Доказаны теоремы о [СВОЙСТВО 1], [СВОЙСТВО 2] и [СВОЙСТВО 3].
Акцент делается на [МИНИМАЛЬНОСТЬ УСЛОВИЙ / ЯВНОСТЬ ФОРМУЛ / НОВЫЙ МЕТОД].

Полученные результаты [дополняют и обобщают / уточняют / являются обобщением]
результаты [ИМЕНА ПРЕДШЕСТВЕННИКОВ ИЛИ КЛАССИЧЕСКАЯ ТЕОРИЯ].

[Для обзора: Библиография: N названий.]
```

## 5.5. Чего не должно быть в аннотации

1. слов «актуальный», «важный», «впервые» как самооценки;
2. ссылок вида `[12]`;
3. вопросов;
4. обещаний будущих работ;
5. длинного контекста до объекта.


# 6. Шаблон введения

## 6.1. Допустимые дебюты

### Дебют A. Объект формулой

```текст
В статье изучается оператор
[ФОРМУЛА (1)],
действующий в пространстве [ПРОСТРАНСТВО] на области
[ФОРМУЛА (2)],
где [РАСШИФРОВКА].
```

Примеры: [Ст. 27], [Ст. 26], [Ст. 28 / ручной мануал].

### Дебют B. Напоминание определений

```текст
Напомним основные определения теории [ОБЛАСТЬ].
Пусть [ОБЪЕКТ] …
```

Примеры: [Ст. 17], [Ст. 23], [Ст. 5].

### Дебют C. Классическая теория как фон

```текст
В классической теории [ОБЪЕКТОВ] стандартным условием является [УСЛОВИЕ].
В настоящей работе рассматривается [ОБОБЩЕНИЕ].
```

Примеры: [Ст. 3 / ручной мануал], [Ст. 22].

### Дебют D. Прикладная задача

```текст
Начальная задача, которая явилась основой настоящей работы, возникает
при рассмотрении [ФИЗИЧЕСКАЯ / МЕХАНИЧЕСКАЯ ЗАДАЧА].
```

Примеры: [Ст. 26], [Ст. 24], [Ст. 8].

## 6.2. Обязательные такты введения

1. объект;
2. условия;
3. история;
4. пробел;
5. цель;
6. анонс результата;
7. факультативно: план статьи или методологическое замечание.

## 6.3. Заполняемый каркас введения

```текст
Абз. 1. Объект.
В статье изучается [ОПЕРАТОР / УРАВНЕНИЕ / СИСТЕМА]
[ФОРМУЛА (1)],
действующий в [ПРОСТРАНСТВО] с областью определения
[ФОРМУЛА (2)].
Здесь [РАСШИФРОВКА ОБОЗНАЧЕНИЙ].

Абз. 2. Условия.
Функции [КОЭФФИЦИЕНТЫ] предполагаем [СВОЙСТВА].
Если [СИТУАЦИЯ], то [УТОЧНЕНИЕ].
Всюду далее [СОГЛАШЕНИЕ].

Абз. 3. История.
Задачам о [ТЕМА] посвящено достаточно много работ,
из которых отметим [k]–[m].
[ИМЯ 1] получил [РЕЗУЛЬТАТ];
[ИМЯ 2] распространил это на [СЛУЧАЙ].
Эта тема имеет давнюю историю.

Абз. 4. Пробел.
Однако во всех этих работах [ОГРАНИЧЕНИЕ].
Такое предположение было существенно для методов исследования.
Нам неизвестны работы, в которых [ОБОБЩЕНИЕ].

Абз. 5. Цель и анонс.
Цель работы — [ПОЛУЧИТЬ / ОБСУДИТЬ / ПРЕДСТАВИТЬ / ВОСПОЛНИТЬ].
Основной результат будет получен в теореме [N]:
[ФОРМУЛИРОВКА ОДНОЙ ФРАЗОЙ].

Абз. 6. Метод / границы.
Для реализации этой цели используется [МЕТОД].
Случай [ТРУДНЫЙ СЛУЧАЙ] требует особого подхода,
ему будет посвящена отдельная работа.
```

## 6.4. Антипримеры для введения

Нельзя:

1. начинать с «В последние годы возрос интерес к…»;
2. писать «насколько нам известно»;
3. перечислять вклад маркированным списком;
4. заканчивать введение вопросом;
5. писать «статья организована следующим образом» в коротких текстах.
