# 2. Архитектура статьи у автора

Наблюдения над корпусом (таблица текстов — в `14-manual-corpus.md`). Порядок частей как
правило дан в `SKILL.md`; здесь — как он выглядит в корпусе и что стоит в каждом блоке.

## 2.1. Что есть и чего нет в текстах корпуса

В большинстве текстов присутствуют:

1. заголовок;
2. авторы;
3. аннотация или её функциональный эквивалент;
4. введение или первый пункт, заменяющий введение;
5. формулировки результатов;
6. список литературы;
7. сноска о финансировании или журнальные метаданные, если они сохранились в файле.

Встречаются не всегда:

1. оглавление — в мемуарах и крупных обзорах [Ст. 3, Ст. 4];
2. абзац-план работы — в крупных текстах [Ст. 16];
3. благодарность людям перед списком литературы [Ст. 16, Ст. 17, Ст. 24] или в конце
   введения [Ст. 4];
4. раздел примеров в конце [Ст. 4, Ст. 9, Ст. 18, Ст. 22];
5. комментарии к истории вопроса — в лекционном тексте [Ст. 1].

Не встречаются:

1. отдельный раздел «Заключение»;
2. отдельный раздел «Открытые проблемы» как финал;
3. приложение как обычный блок;
4. нумерованный список «вкладов» во введении;
5. маркированные списки как обычное оформление.

## 4. Обобщённый порядок частей

Линия изложения (она же — основной тип нарратива автора, см. `03-narrative.md`):

```text
Объект
→ соглашения и определения
→ историческая линия
→ пробел / ограничение прежних подходов
→ цель
→ анонс результата
→ формальные формулировки
→ доказательство
→ граница / расширение / контрпример
```

Типичная исследовательская статья корпуса объёмом 10–25 страниц устроена так. Это
описание сложившегося порядка; разделы конкретной статьи называются по её содержанию, и
число их определяется материалом.

```text
ЗАГОЛОВОК, АВТОРЫ, АННОТАЦИЯ
ключевые слова, УДК, DOI, сноска о гранте — по требованиям журнала

§1. Введение
    объект формулой или напоминание определений
    условия, класс коэффициентов
    история вопроса
    пробел
    цель
    анонс главного результата

§2. Определения, вспомогательные результаты (иногда и основной результат)
    определения центральных понятий
    сквозные соглашения
    напоминания известных фактов с адресами

§3. Основные результаты
    теоремы, критерии

§4. Доказательства
    шаги, словари замен, ссылки вместо стандартных выкладок

[§5. Примеры или приложения метода — встречается не всегда]

Благодарность — если есть, перед списком литературы
СПИСОК ЛИТЕРАТУРЫ
```

В корпусе есть и другие раскладки: главный результат прямо во введении [Ст. 13, Ст. 28],
формулировки и доказательства в одном разделе [Ст. 17, Ст. 25], разделы по случаям
[Ст. 9], разделы по методам [Ст. 27].

## 4.1. Что делает каждый блок

| Блок | Функция | Какие обороты здесь встречаются |
|---|---|---|
| Введение | ввести объект, историю, пробел, цель | «В статье изучается…», «Цель работы…», «Однако…» |
| Определения | задать класс объектов | «назовём …, если…», «Будем говорить…» |
| Вспомогательные результаты | подготовить инструменты | «Напомним…», «Известно [n, гл. …], что…» |
| Основные результаты | сформулировать вклад | «Сформулируем основной результат…» |
| Доказательства | провести рассуждение по объявленному плану | «Шаг 1», «Заметим, что…», «Теорема доказана.» |
| Финал | обозначить границу | «Отметим, что…», «Но в этой заметке мы не будем…» |
