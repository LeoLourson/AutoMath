# 4. Обобщённый шаблон архитектуры статьи

Для типичной исследовательской статьи объёмом 10–25 страниц.

```текст
ЗАГОЛОВОК
АВТОРЫ
АННОТАЦИЯ
КЛЮЧЕВЫЕ СЛОВА / УДК / DOI — по журналу
сноска о гранте, если требуется

§1. Введение
    1) объект формулой или напоминание определений
    2) условия / класс коэффициентов
    3) история вопроса
    4) пробел
    5) цель
    6) анонс главного результата

§2. Определения / вспомогательные результаты / основной результат
    - определения через «назовём»
    - соглашения «здесь и далее»
    - напоминания известных фактов с адресами

§3. Основные результаты
    - теоремы в схеме «Пусть … Тогда … Более того …»
    - критерии через «необходимо и достаточно»

§4. Доказательства
    - шаги
    - словари замен
    - экономия на стандартном

[§5. Примеры / приложения метода — факультативно]

Благодарность — факультативно, перед списком литературы

СПИСОК ЛИТЕРАТУРЫ
```

## 4.1. Функция блоков

| Блок | Функция | Типичные фразы |
|---|---|---|
| Введение | ввести объект, историю, пробел, цель | «В статье изучается…», «Цель работы…», «Однако…» |
| Определения | задать класс объектов | «назовём …, если…», «Будем говорить…» |
| Вспомогательные результаты | подготовить инструменты | «Напомним…», «Известно [n, гл. …], что…» |
| Основные результаты | сформулировать вклад | «Сформулируем основной результат…» |
| Доказательства | реализовать план | «Шаг 1», «Заметим, что…», «Теорема доказана.» |
| Финал | обозначить границу | «Отметим, что…», «Но в этой заметке мы не будем…» |
