# 12. Примеры, контрпримеры и замечания

## 12.1. Примеры

Примеры у автора редки. Они чаще появляются:

1. в обзорах как демонстрация применимости [Ст. 4];
2. в конце кратких сообщений как граница применимости [Ст. 6, Ст. 22];
3. в классификационных анонсах [Ст. 9];
4. в учебных и монографических текстах [Ст. 1].

Шаблон примера в конце:

```текст
Пример. Пусть [КОНКРЕТНЫЙ ОБЪЕКТ].
Простая проверка показывает, что [СВОЙСТВО].
Следовательно, [ГРАНИЦА ПРИМЕНИМОСТИ].
```

## 12.2. Контрпримеры

Шаблон:

```текст
[УТВЕРЖДЕНИЕ О НЕВОЗМОЖНОСТИ].
Это видно уже на примере [ПРОСТЕЙШИЙ КЛАСС].
Если, например, [КОНКРЕТИЗАЦИЯ], то [НАРУШЕНИЕ].
```

Пример: [Ст. 15 / ручной мануал §11.2].
