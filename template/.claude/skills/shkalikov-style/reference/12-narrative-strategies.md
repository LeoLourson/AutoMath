# 18. Нарративные стратегии и шаблоны математического рассказа

## 18.1. Стратегия «от известного к новому»

Шаблон:

```текст
Классическая теория
→ имена предшественников
→ ограничение классической теории
→ новое условие / новый класс
→ обобщение
```

Примеры: [Ст. 13, Ст. 22, Ст. 23].

## 18.2. Стратегия «заполнения пробела»

Шаблон:

```текст
Имеются работы [список].
Однако во всех них [ОГРАНИЧЕНИЕ].
Нам неизвестны работы, в которых [ОБОБЩЕНИЕ].
Цель работы — восполнить этот пробел.
```

Примеры: [Ст. 25, Ст. 13, Ст. 14].

## 18.3. Стратегия «два метода»

Шаблон:

```текст
Предложены два метода исследования [ОБЪЕКТА].
Первый метод основан на [МЕТОД 1].
Второй метод основан на [МЕТОД 2].
```

Пример: [Ст. 27].

## 18.4. Стратегия «редукция как сюжет»

Шаблон:

```текст
Исходное уравнение
→ сведение к системе первого порядка
→ общая теорема для систем
→ возврат к исходному уравнению
```

Примеры: [Ст. 16, Ст. 27].

## 18.5. Стратегия «классификация»

Шаблон:

```текст
Объект
→ параметры
→ разбиение на случаи
→ для каждого случая свой класс
→ итоговая классификация
```

Примеры: [Ст. 9, Ст. 25].

## 18.6. Стратегия «оценка и асимптотика»

Шаблон:

```текст
Постановка
→ редукция
→ ключевая оценка
→ асимптотическое представление
→ уточнение при большей гладкости
```

Примеры: [Ст. 14, Ст. 15, Ст. 26].

## 18.7. Приёмы нарративного напряжения

| Приём | Пример |
|---|---|
| отложенный результат | анонс теоремы во введении [Ст. 28] |
| конфликт теорем | более общая теорема даёт меньше в нужном секторе [Ст. 28] |
| нагнетание лемм | [Ст. 20, Ст. 15] |
| ложный след | [Ст. 24] |
| финальная граница | [Ст. 15, Ст. 14] |
| расширение после доказательства | [Ст. 28] |

## 18.8. Приёмы разгрузки

1. «Напомним…»;
2. «Заметим, что…»;
3. шаги доказательства;
4. словари замен;
5. явные соглашения;
6. замечания после технических блоков.
