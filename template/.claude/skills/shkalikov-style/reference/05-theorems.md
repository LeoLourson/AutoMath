# 9. Шаблоны формулировок теорем, лемм, предложений и следствий

## 9.1. Иерархия окружений

| Окружение | Функция у автора |
|---|---|
| Теорема | главный результат или существенный факт |
| Предложение | самостоятельный, переиспользуемый факт среднего веса |
| Лемма | техническая ступень |
| Замечание | ограничение, расширение, пояснение, контрпример |
| Определение | центральное понятие |
| Пример | редкий жанр; чаще в обзорах или в конце статьи |
| Следствие | редко; чаще через «Из теоремы N получаем…» |
| Гипотеза | только в обзоре [Ст. 5] |

## 9.2. Трёхтактная схема теоремы

```текст
Теорема [N]. Пусть [ОБЪЕКТ] — [ТИП], и пусть выполнены следующие условия:
(i) [УСЛОВИЕ 1] (а потому [СЛЕДСТВИЕ УСЛОВИЯ]);
(ii) [УСЛОВИЕ 2] при некотором (а тогда при всех) [ПАРАМЕТР];
(iii) [УСЛОВИЕ 3].

Тогда [ЗАКЛЮЧЕНИЕ].

Более того, [УСИЛЕНИЕ].

Здесь [РАСШИФРОВКА ОБОЗНАЧЕНИЙ].
```

Примеры:

- главная теорема с условиями (i)–(iv) [Ст. 23];
- асимптотическая теорема с «Более того» при большей гладкости [Ст. 26].

## 9.3. Критерии

Формулы:

```текст
Для того, чтобы [СВОЙСТВО] выполнялось [ГДЕ],
необходимо и достаточно, чтобы [УСЛОВИЕ].
```

```текст
[СВОЙСТВО] имеет место в том и только том случае, когда [УСЛОВИЕ].
```

Примеры:

- критерии Биркгофа и Шлезингера [Ст. 15];
- критерий аналитичности полугруппы [Ст. 20].

## 9.4. Скобочные параллельные утверждения

```текст
Пусть задача регулярна в правой (левой) полуплоскости.
Тогда оператор \(T\) (\(-T\)) является генератором …
```

Пример: [Ст. 7 / ручной мануал §8.6].

## 9.5. Шаблоны лемм и следствий

### Лемма

```текст
Лемма [N]. Пусть [МИНИМАЛЬНОЕ УСЛОВИЕ].
Тогда [ТЕХНИЧЕСКОЕ ЗАКЛЮЧЕНИЕ].
```

### Предложение

```текст
Предложение [N]. Пусть [ОБЪЕКТ] обладает [СВОЙСТВОМ].
Тогда [САМОСТОЯТЕЛЬНЫЙ ФАКТ], который будет использован далее для [ЦЕЛЬ].
```
