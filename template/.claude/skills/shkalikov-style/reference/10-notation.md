# 15. Нотационный словарь автора

Ниже — объединённый словарь. Он не претендует на полноту всех 28 файлов, но фиксирует устойчивые роли символов.

## 15.1. Пространства

| Объект | Обозначение | Типовая фраза |
|---|---|---|
| Гильбертово пространство | \(H\) | «Пусть \(H\) — гильбертово пространство» |
| Разложение по знаку метрики | \(H = H_+ \oplus H_-\) | «Представим пространство \(H\) в виде ортогональной суммы…» |
| Пространство Понтрягина | \(\Pi_\kappa\) | «называют пространством Понтрягина и обозначают \(\Pi_\kappa\)» |
| Лебеговы пространства | \(L_2[a,b]\), \(L_1[0,1]\), \(L_p\) | стандартно |
| Соболевские пространства | \(W_p^k[0,1]\) | «Здесь и далее \(W_p^k[0,1]\) — пространства Соболева» |
| Область определения | \(D(A)\), иногда \(\mathcal D(L)\) | «с областью определения \(D(A)\)» |
| Шкала пространств | \(H_\theta = D(T^{\theta/2})\) | [Ст. 21, Ст. 20] |

## 15.2. Операторы

| Роль | Буква | Комментарий |
|---|---|---|
| Главный дифференциальный оператор | \(L\) | статьи о краевых задачах |
| Абстрактный оператор | \(A\), \(T\) | операторные статьи |
| Невозмущённый оператор | \(T\) | в задачах \(A=T+B\) |
| Возмущение | \(B\) | там же |
| Инволюция / симметрия | \(J\) | \(Jy(x)=y(-x)\) |
| Проекторы | \(P_+\), \(P_-\) | разложение пространства |
| Угловой оператор | \(K\) | представление подпространства |
| Блоки матрицы | \(A_{11}, A_{12}, A_{21}, A_{22}\) | блочные операторы |
| Функция Шура | \(S(\mu)\) | \(S(\mu)=A_{11}-A_{12}(A_{22}-\mu)^{-1}A_{21}\) |
| Пучок | \(L(\lambda)=\lambda^2+\lambda A+C\) | квадратичные пучки |

## 15.3. Матрицы и системы ОДУ

| Объект | Обозначение | Комментарий |
|---|---|---|
| Диагональная главная часть | \(A(x)=\operatorname{diag}\{a_j(x)\}\) или \(B(x)\) | буквы могут меняться между статьями |
| Младшая матрица | \(B(x)=\{b_{jk}(x)\}\) или \(A(x)=\{a_{jk}(x)\}\) | зависит от статьи |
| Малое возмущение | \(C(x,\lambda)\) | \(\|c_{jk}\|\to0\) |
| Экспоненциальная матрица | \(E(x,\lambda)\) | диагональные экспоненты |
| Матрица нормировки | \(M(x)\) | экспоненциальные множители |
| Фундаментальная матрица | \(Y(x,\lambda)\) | основной объект асимптотики |
| Остаток | \(R(x,\lambda)\) | \(|R|\to0\) |
| Характеристический определитель | \(\Delta(\lambda)\), \(\Delta(\rho)\) | регулярность |

## 15.4. Параметры и константы

| Роль | Обозначение | Правило |
|---|---|---|
| Спектральный параметр | \(\lambda\) | почти всегда |
| Корень | \(\rho\), \(\lambda=\rho^n\) | в задачах высших порядков |
| Точка резольвентного множества | \(\mu\) | в формулах с резольвентой |
| Раствор сектора | \(\alpha\), \(\theta\) | секторы комплексной плоскости |
| Малые положительные | \(\varepsilon\), \(\delta\) | оценки и разделения |
| Константы | \(C\), \(C_1\), \(C_2\), \(M\), \(const\) | зависимость оговаривается явно |

## 15.5. Асимптотические символы

- \(o(1)\);
- \(O(\lambda^{-2})\);
- \(\to\) — обычная сходимость;
- \(\Rightarrow\) — сходимость по норме [ручной мануал];
- \(\rightharpoonup\) — слабая сходимость;
- \(\equiv\) — тождественно;
- \(:=\) — определяющее равенство;
- «п.в.» — почти всюду.
