# 10. Шаблоны доказательств

## 10.1. Зачины доказательств

| Тип | Начало | Пример функции |
|---|---|---|
| прямое | «Доказательство. Пусть …» | сразу вход в объект |
| наблюдение | «Доказательство. Заметим, что …» | ключевая мысль |
| подготовка | «Доказательство. Прежде всего отметим …» | снятие простого случая |
| редукция | «Очевидно, достаточно доказать …» | упрощение |
| конструкция | «Сделав замену …, получим …» | конструктивный ход |
| аппарат | «Доказательство. Оно основано на …» | ссылка на метод |
| шаги | «Доказательство разобьем на несколько шагов.» | длинное доказательство |

## 10.2. Объявление плана

```текст
Далее идея доказательства состоит в следующем.
Поскольку [ФАКТ], то [СЛЕДСТВИЕ].
Мы покажем, что [ЦЕЛЬ].
Отметим, что сразу доказать [НАИВНЫЙ ПУТЬ] затруднительно,
так как [ПРИЧИНА].
Теперь реализуем намеченный план.
```

[ручной мануал §9.3; Ст. 23 / Ст. 17]

## 10.3. Разбиение на шаги

```текст
Доказательство разобьем на несколько шагов.

Шаг 1. [НАЗВАНИЕ / ДЕЙСТВИЕ].
...

Шаг 2. [НАЗВАНИЕ / ДЕЙСТВИЕ].
...

Теорема доказана.
```

Примеры:

- [Ст. 23];
- [Ст. 12];
- [Ст. 13].

## 10.4. Экономия и словари замен

Правильная форма аналогии:

```текст
Доказательство повторяет [ИСТОЧНИК / РАССУЖДЕНИЕ ВЫШЕ]
с заменой [A] на [B] и [УСЛОВИЕ 1] на [УСЛОВИЕ 2].
```

Примеры:

- «достаточно повторить рассуждения из первой части с заменой …» [Ст. 15];
- «Аналогичная лемма доказана в [12]. Здесь условия на коэффициенты другие, но идея сохраняется.» [Ст. 14].

## 10.5. Отказ от доказательства с адресом

```текст
Доказательство получается почти дословным повторением рассуждений
из работы [n, § m] и здесь не приводится.
```

```текст
Доказательство будет представлено в другой работе.
```

```текст
Мы не приводим здесь определение [ПОНЯТИЕ], отсылая читателя
к монографиям [n], [m].
```

## 10.6. Концовки доказательств

| Формула | Когда |
|---|---|
| «Теорема доказана.» | стандартное завершение |
| «Лемма доказана.» | завершение леммы |
| «Предложение доказано.» | завершение предложения |
| «Теорема полностью доказана.» | длинное доказательство, собранное из частей |
| «Этим завершается доказательство теоремы.» | альтернативная форма |
| `□` | встречается, но не заменяет словесную форму в крупных русских текстах |


# 14. Каталог доказательных приёмов

| Приём | Как используется | Маркеры | Пример | Шаблон |
|---|---|---|---|---|
| Доминантный оператор + возмущение | строится явно решаемая часть, затем подчинённое возмущение | «доминантный оператор», «подчинённое возмущение» | [Ст. 27, Ст. 4] | построить \(T\), доказать свойства \(T\), применить теорию возмущений к \(T+B\) |
| Сведение к системе первого порядка | скалярное уравнение высокого порядка превращается в систему | «сводится к системе», «редукция» | [Ст. 16, Ст. 27] | ввести вектор, получить систему, применить общую теорему |
| Диагонализация заменой | замена \(y = W(x)z\) приводит к диагональному виду | «Умножая уравнение…» | [Ст. 7 / ручной мануал] | выбрать \(W\), вычислить \(W^{-1} A W\) |
| Матричное представление 2×2 | оператор пишется блоками, используется функция Шура | \(A_{11}, A_{12}, A_{21}, A_{22}\), \(S(\mu)\) | [Ст. 23, Ст. 17] | разложить пространство, получить блочную матрицу |
| Конечномерная аппроксимация | задача решается на конечных подпространствах, затем предел | «слабая операторная топология» | [Ст. 23] | \(K_n\), выделить подпоследовательность, перейти к пределу |
| Контурное интегрирование | выделение спектральной части проектором Рисса | «жорданов контур», «проектор Рисса» | [Ст. 23 / ручной мануал] | выбрать \(\Gamma\), интегрировать резольвенту |
| Оценка резольвенты вне кружков | контроль резольвенты вне малых окрестностей собственных значений | «вне кружков фиксированного радиуса» | [Ст. 7 / ручной мануал] | доказать оценку \(|G|\le const\) вне кружков |
| Характеристический определитель | регулярность через квазиполином Дирихле | \(\Delta_0(\lambda)\), «индикаторная диаграмма» | [Ст. 7, Ст. 25] | выписать \(\Delta\), исследовать крайние экспоненты |
| Достаточность / необходимость | стандартная разбивка критерия | «Достаточность.», «Необходимость.» | [Ст. 15] | отдельно доказать импликации |
| Наследование доказательства | второе доказательство как дельта к первому | «Рассуждение сохраняется. Отличие состоит в…» | [Ст. 15] | указать словарь замен |
| Проверка согласованности | новое определение совпадает со старым на старом классе | «совпадают с классическим определением» | [Ст. 22] | показать эквивалентность при старых условиях |
| Сборка доказанного | главная теорема собирается из ранее полученных элементов | «Essentially, the proof is already complete.» | [Ст. 10, Ст. 12] | сослаться на леммы и формулы |
