# 20. Пошаговый сценарий написания новой статьи в стиле А. А. Шкаликова

1. Определить жанр: исследовательская статья, краткое сообщение, анонс, обзор, учебный текст.
2. Выбрать целевой объём:
   - краткое сообщение: 5–6 страниц;
   - малая статья: 10–20 страниц;
   - средняя статья: 17–24 страницы;
   - крупная статья: 38+ страниц.
3. Выбрать систему нумерации:
   - сквозная для коротких текстов;
   - посекционная для крупных;
   - смешанная при необходимости.
4. Выписать главный объект одной формулой.
5. Выписать условия на коэффициенты отдельным блоком.
6. Если условий больше двух, дать им имена.
7. Сформулировать главную теорему в схеме:
   - «Пусть …»;
   - «Тогда …»;
   - «Более того, …».
8. Проверить, все ли обозначения теоремы расшифрованы.
9. При необходимости добавить такт «Здесь …».
10. Подготовить вспомогательные леммы или предложения.
11. Решить, где живут леммы:
    - в отдельном разделе;
    - непосредственно перед доказательством;
    - внутри доказательства.
12. Написать введение по шестиабзацному каркасу.
13. История должна объяснять, почему возник пробел, а не просто перечислять работы.
14. Пробел сформулировать через «Однако…» или «Нам неизвестны…».
15. Цель сформулировать инфинитивом.
16. Анонсировать главный результат прозой.
17. При крупных размерах добавить план: «Структура работы следующая…».
18. Ввести сквозные соглашения: «Здесь и далее…», «Всюду далее…».
19. Определения центральных объектов дать через «назовём».
20. Для служебных понятий использовать курсив внутри абзаца.
21. После определения добавить проверку согласованности с классическим случаем.
22. Доказательства нового расписывать подробно.
23. Стандартные места заменять ссылкой или словарём замен.
24. Длинные доказательства разбить на шаги.
25. Перед длинным доказательством объявить план.
26. Каждое доказательство закрыть словами:
    - «Теорема доказана.»;
    - «Лемма доказана.»;
    - «Теорема полностью доказана.».
27. Примеры не рассыпать по тексту.
28. Контрпримеры и ограничения прятать в замечания или финал.
29. Не писать заключение.
30. Финал посвятить границе:
    - ослабление условия;
    - расширение результата;
    - контрпример;
    - признание нерешённого случая.
31. Добавить благодарность людям перед списком литературы, если нужно.
32. Грант оформить сноской на первой странице, если требует журнал.
33. Проверить ссылки: у фактов должны быть внутренние адреса источников.
34. Прогнать текст по чеклисту.
35. Удалить антипаттерны: «актуально», «впервые», «заключение», буллиты, гипотезы без жанра обзора.


# 21. Чеклист соответствия стилю автора

## 21.1. Архитектура

- [ ] Введение начинается с математики, а не с актуальности.
- [ ] Цель заявлена инфинитивом.
- [ ] Есть историческая справка с именами.
- [ ] Пробел сформулирован явно.
- [ ] Главный результат анонсирован прозой.
- [ ] Нет раздела «Заключение».
- [ ] Финал посвящён границе, расширению или нерешённому случаю.
- [ ] Нет приложения, если это не учебный текст.
- [ ] Разделы имеют содержательные названия.

## 21.2. Аннотация

- [ ] Объём 45–110 слов.
- [ ] Начинается с объекта.
- [ ] Содержит условия.
- [ ] Содержит указание доказанных свойств.
- [ ] Заканчивается отношением к предшественникам.
- [ ] Нет ссылок `[n]`.
- [ ] Нет слов «актуальный», «важный», «впервые».

## 21.3. Определения

- [ ] Центральное определение дано через «назовём …, если…».
- [ ] Служебные определения введены курсивом или фразой «будем говорить».
- [ ] Есть мотивировка определения.
- [ ] Есть проверка согласованности с классическим случаем.
- [ ] При необходимости дана двухступенчатая шкала классов.

## 21.4. Теоремы

- [ ] Схема «Пусть … Тогда … Более того …».
- [ ] Условия вынесены в `(i)`, `(ii)`, `(iii)` при числе гипотез ≥ 3.
- [ ] Есть скобочные ремарки вида «а тогда при всех».
- [ ] Обозначения расшифрованы в такте «Здесь …».
- [ ] Критерии используют «необходимо и достаточно».
- [ ] Своим теоремам не даны имена.

## 21.5. Доказательства

- [ ] Есть стандартный зачин.
- [ ] Длинные доказательства разбиты на шаги.
- [ ] Перед длинным доказательством объявлен план.
- [ ] Пропуски оформлены ссылкой или словарём замен.
- [ ] Доказательство закрыто словесной формулой.
- [ ] Нет окружения `Claim`.
- [ ] Нет внутренних утверждений вида «Утверждение 1».

## 21.6. Формулы

- [ ] Нумеруются только цитируемые формулы.
- [ ] Формула не начинает предложение.
- [ ] После формулы правильная пунктуация.
- [ ] Константы введены явно.
- [ ] Зависимость констант оговорена.
- [ ] \(o(1)\) расшифрован при первом появлении.

## 21.7. Ссылки

- [ ] Ссылки на свои утверждения строчными.
- [ ] У чужих фактов есть адрес внутри источника.
- [ ] Приоритет предшественников признан.
- [ ] Критика точечная и конструктивная.

## 21.8. Голос и нарратив

- [ ] Повествование от «мы» или безличное.
- [ ] Нет «я».
- [ ] Нет гипотез и «мы ожидаем».
- [ ] Новизна заявлена через зазор и минимальность условий.
- [ ] Границы работы обозначены честно.


# 22. Антипаттерны: чего делать нельзя

1. Не начинать введение с общих слов об актуальности.
2. Не писать «В последние годы возрос интерес к…».
3. Не использовать «насколько нам известно».
4. Не писать «The paper is organized as follows» в коротких статьях.
5. Не заканчивать статью разделом «Заключение».
6. Не делать список открытых проблем отдельным финальным разделом.
7. Не давать своим теоремам имена.
8. Не использовать окружение `Claim`.
9. Не нумеровать внутренние шаги доказательства как отдельные утверждения.
10. Не использовать обозначения гипотез `(A1)`, `(H1)`.
11. Не использовать маркированные списки для вклада или условий.
12. Не рассыпать примеры по тексту как иллюстрации определений.
13. Не оставлять «голые» ссылки на чужие факты.
14. Не писать «предоставляем читателю проверить».
15. Не использовать «оптимальный», «наилучший» как самооценку.
16. Не писать «впервые» без крайней необходимости.
17. Не формулировать гипотезы в исследовательской статье, если это не жанр обзора.
18. Не смешивать системы нумерации внутри одного текста без единообразия.
19. Не начинать предложение с формулы.
20. По имеющимся данным, автор избегает доказательств от противного как несущей конструкции; их можно использовать только как локальный ход `[предварительно]`.
