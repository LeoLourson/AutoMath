# Как говорят в математическом тексте

Банк конструкций русского математического текста, разложенный по задачам автора. Это
иллюстрации, а не обязательный набор: файл открывают, когда лишний оборот снят и нужна
формулировка на его место. Конструкция выбирается по смыслу фразы; одна и та же подряд
даёт тот же однообразный рисунок, что и штамп. Если для файла задан стиль автора, его
обороты и порядок частей первичны.

## Введение и постановка

| Задача | Конструкция | Пример |
| --- | --- | --- |
| назвать предмет | «В работе рассматривается…», «Мы изучаем…», «Статья посвящена…» | «В работе рассматривается задача о спектре оператора Шрёдингера с потенциалом, убывающим степенным образом.» |
| показать пробел | «До сих пор оставался открытым вопрос о…», «Не решён вопрос о…», «Нам неизвестны работы, в которых…» | «До сих пор оставался открытым вопрос о сходимости ряда при $p=1$.» |
| сузить задачу | «Мы ограничиваемся случаем…», «Здесь мы не касаемся…» | «Мы ограничиваемся гладкими потенциалами; негладкий случай требует отдельного исследования.» |
| назвать цель | «Цель работы — …», «Задача состоит в том, чтобы…» | «Цель работы — получить асимптотику собственных значений при $\varepsilon\to0$.» |
| показать новое сравнением | «В отличие от [3], где…, мы…» | «В отличие от [3], где рассматривался случай $d=2$, мы работаем в произвольной размерности.» |

Статья не начинается с актуальности («В настоящее время эта проблематика приобретает всё
большую актуальность…») и с описания намерений («Настоящая работа направлена на
всестороннее изучение…»). Новизну показывает сравнение с известным; слова «впервые» и
«новым является» её не показывают.

## Определения, обозначения, соглашения

| Конструкция | Пример |
| --- | --- |
| «Будем говорить, что…, если…» | «Будем говорить, что последовательность $x_n$ сходится слабо, если $f(x_n)\to f(x)$ для любого непрерывного линейного функционала $f$.» |
| «Под … мы понимаем…» | «Под решением мы понимаем функцию из $W_2^2$, удовлетворяющую уравнению почти всюду.» |
| «Определим … равенством…» | «Определим норму $\lVert f\rVert_\alpha$ равенством (2.3).» |
| «Пусть … — …» | «Пусть $\Omega$ — ограниченная область в $\mathbb R^n$ с гладкой границей.» |
| «… называется …, если…» | «Функция называется гармонической, если $\Delta u=0$ в $\Omega$.» |
| «Будем называть … …, если…» | «Будем называть решение классическим, если $u\in C^2(\Omega)\cap C(\overline\Omega)$.» |
| «Обозначим через…» | «Обозначим через $\lambda_1$ наименьшее собственное значение.» |
| «Положим…» | «Положим $\varepsilon=1/n$.» |
| «Запишем … в виде…» | «Запишем решение в виде ряда Фурье.» |
| «Для краткости пишем…» | «Для краткости пишем $H$ вместо $L_2(\Omega)$.» |
| «Здесь и далее…», «Всюду ниже…» | «Здесь и далее $C$ обозначает постоянную, не зависящую от $\varepsilon$.» |
| «Если не оговорено противное, …» | «Если не оговорено противное, все функции предполагаются гладкими.» |
| «Мы не различаем…» | «Мы не различаем функции, совпадающие почти всюду.» |

## Формулировка утверждений

| Элемент | Конструкция | Пример |
| --- | --- | --- |
| условие | «Пусть выполнены условия (1)–(3).», «Если…, то…» | «Пусть $V\in L_\infty(\mathbb R)$ и $V(x)\to0$ при $\lvert x\rvert\to\infty$.» |
| вывод | «Тогда…», «Справедлива оценка…», «Имеет место равенство…» | «Тогда спектр оператора дискретен.» |
| второе заключение | «Более того, …» | «Более того, собственные подпространства конечномерны.» |
| уточнение | «Равенство достигается тогда и только тогда, когда…» | «Равенство в (7) достигается тогда и только тогда, когда $u=0$.» |
| исключение | «За исключением случая…» | «За исключением случая $\lambda=0$ решение единственно.» |

| «В силу теоремы 1…» | «В силу теоремы 1 решение существует и единственно.» |

Начало:

| Конструкция | Пример |
| --- | --- |

## Литература и критика

| Конструкция | Пример |
| --- | --- |
| «Как показано в [3], …» | «Как показано в [3], решение единственно при $p>2$.» |
| «Задача исследовалась в работах…» | «Задача исследовалась в работах [1–5]; во всех коэффициент предполагается гладким.» |
| «Первое доказательство принадлежит…» | «Первое строгое доказательство принадлежит Колмогорову [4].» |
| «Мы следуем [7]» | «Мы следуем подходу [7], перенося его на несамосопряжённый случай.» |
| «Подробный обзор см. в [9].» | отсылка без пересказа |
| «Ср. также [6], где…» | «Ср. также [6], где получен аналогичный результат для эллиптического случая.» |
| «Независимо этот результат получен в [8].» | признание приоритета |
| «В [3] утверждается, что…; однако…» | «В [3] утверждается, что решение гладкое; однако доказательство содержит пробел в шаге 2.» |
| «В [4] допущена неточность: …» | «В [4] допущена неточность: формула (3.2) верна только при $n>1$.» |
| «Результат [6] требует уточнения: …» | «Результат [6] требует уточнения: постоянная $C$ зависит от $\varepsilon$.» |

Критика называет место и то, что в нём неверно; оценок работе и автору она не даёт.

## Переходы

| Задача | Конструкция |
| --- | --- |
| новый объект | начать с определения: «Перейдём к случаю $d\ge3$. Пусть $\Omega\subset\mathbb R^d$.» |
| доказательство | «Докажем теорему 1.» |
| примеры | «Приведём два примера.» |
| проверка расчётом | «Проверим асимптотику (15) численно.» |
| границы | «Укажем границы применимости метода.» |
| возврат | «Вернёмся к уравнению (3).», «Напомним определение (2.1).» |

Переход называет следующий шаг одной короткой фразой. Фразы вроде «Теперь, когда мы
установили основные факты, можем приступить к…» шага не называют.

## Неуверенность и границы

Доказанное утверждается прямо: «Имеет место равенство (7)», «Справедлива оценка…», «Тем
самым предел существует», «Дополнительных предположений не требуется».

Недоказанное называется недоказанным, одной пометкой:

| Конструкция | Пример |
| --- | --- |
| «Нам неизвестно, …» | «Нам неизвестно, образуют ли корневые функции базис при знакопеременном $a$.» |
| «Не доказано, что…», «Вопрос открыт.» | «При $\lambda=0$ вопрос открыт.» |
| «По-видимому, …», «Вероятно, …» | «По-видимому, условие (4) можно ослабить.» |

Формулируются ли в статье гипотезы и ожидания, решает стиль автора.

Точные границы:

| Конструкция | Пример |
| --- | --- |
| «При … это верно; при … вопрос открыт.» | «При $\lambda>0$ это верно; при $\lambda=0$ вопрос открыт.» |
| «Мы не утверждаем, что…; доказано лишь…» | «Мы не утверждаем, что сходимость равномерна; доказана лишь поточечная.» |
| «Строго говоря, …» | «Строго говоря, функция не дифференцируема в нуле; на результат это не влияет.» |
| «С точностью до…» | «Это верно с точностью до $O(\varepsilon^2)$.» |
| «При дополнительных предположениях…» | «При дополнительной гладкости $V$ оценка улучшается до $O(\varepsilon^2)$.» |

## Причина, следствие, условие

| Связь | Конструкции | Пример |
| --- | --- | --- |
| причина | «поскольку», «так как», «в силу», «ввиду», «вследствие», «из-за», «за счёт» | «Решение единственно, поскольку оператор строго монотонен.» «В силу компактности вложения последовательность содержит сходящуюся подпоследовательность.» «Вследствие симметрии достаточно рассмотреть $x>0$.» |
| следствие | «Отсюда», «Следовательно», «Поэтому», «Значит», «Тогда», «Отсюда вытекает» | «Отсюда $\lambda>0$.» «Следовательно, ряд сходится.» «Поэтому достаточно рассмотреть $n\ge2$.» «Значит, $u\equiv0$ в $\Omega$.» |
| итог | «Итак», «Тем самым», «Таким образом» | «Итак, мы пришли к уравнению (12).» |
| условие | «Если…, то…», «Пусть…», «При…», «Предположим, что…», «Допустим, что…» | «Если $f\in C^1$, то решение классическое.» «При $\lambda\ne0$ решение единственно.» |

Связки следствия не взаимозаменяемы: «отсюда» отсылает к только что выписанному,
«следовательно» — к рассуждению, «поэтому» — к причине, названной раньше.
