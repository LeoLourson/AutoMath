# Тезис, уровни утверждений, иерархия

Файл развёртывает разделы «Тезис», «Четыре уровня утверждений», «Иерархия результатов»
и «Таблица канвы» из `SKILL.md`. Примеры составлены для иллюстрации приёма: формой они
не служат, а математические утверждения в них условны.

## Тезис

Тезис — одна фраза, которую читатель может повторить после чтения. Дословно повторять
её в каждом разделе не нужно; достаточно, чтобы про каждый раздел можно было сказать,
какую часть тезиса он доказывает, уточняет или ограничивает.

В тезисе математического текста названы объект, условие, утверждение и, если она есть,
граница. Три разных примера:

- «Для потенциалов из $W_2^{-1}$ собственные функции оператора Штурма–Лиувилля образуют
  базис Рисса; для более сингулярных потенциалов регуляризация неприменима».
- «Условие (2) достаточно для полноты системы корневых функций, но не для базисности: в
  примере 2 оно выполнено, а базиса из собственных функций нет».
- Обзор: «При постоянном коэффициенте задача решена полностью; при переменном полнота и
  базисность доказаны в двух подклассах, а общий случай открыт».

Тезисом не служат:

- тема («изучаются спектральные свойства оператора»): её нельзя ни доказать, ни
  опровергнуть;
- перечень средств («применяются метод подобных операторов и теория возмущений»): он
  говорит, чем пользовались, но не сообщает, что получено;
- перечень результатов одного веса: читатель не узнаёт, ради какого написан текст.

Когда тезис виден в аннотации, введении, разделах с результатами и в финале, у текста
есть канва. Правка языка после этого сводится к чистке вокруг уже выстроенного
аргумента; до этого она лишь меняет слова в тексте, который читателя никуда не ведёт.

## Уровни утверждений

Один и тот же результат на четырёх уровнях:

1. Результат: «Система корневых функций оператора $L$ полна в $L_2(0,1)$».
2. Опора: доказательство через оценку резольвенты на лучах либо ссылка «[k, теорема
   3.1]».
3. Истолкование: «Полнота не требует гладкости коэффициента: в доказательстве участвует
   только его ограниченность».
4. Граница: «О базисности теорема ничего не говорит; пример 2 показывает, что базиса из
   собственных функций может не быть».

Три способа смешать уровни:

- Результат без истолкования. Теорема сформулирована и доказана, а чем она отличается
  от известной, читатель выясняет сам. Он либо не заметит новизны, либо припишет
  результату лишнее.
- Истолкование без границы. «Метод применим к широкому классу операторов» — читатель не
  знает, где класс кончается, и проверить фразу не может.
- Граница внутри результата. «Система, по-видимому, образует базис, хотя в отдельных
  случаях это может нарушаться» — утверждение перестало быть утверждением. Раздельно:
  «Система образует базис при условии (A). При нарушении (A) базиса может не быть
  (пример 3)».

Условие теоремы к третьему случаю не относится: оно входит в результат.

## Иерархия

Пример иерархии для статьи о базисности:

- главный: базис Рисса при условии (A);
- поддерживающие: полнота без условия (A); базис со скобками при более слабом условии
  (B);
- отрицательный: пример, где (B) выполнено, а базиса из собственных функций нет;
- технические: счётная функция собственных значений, оценка резольвенты.

Если все эти утверждения поданы с одной интонацией, читатель не понимает, что из них
важно. Признаки того, что иерархия не показана: аннотация перечисляет утверждения в
порядке их появления в тексте; лемма анонсирована во введении наравне с теоремой;
истолкование есть у вспомогательной оценки и отсутствует у главной теоремы.

Текст показывает вес результата тремя средствами: местом в анонсе, объёмом истолкования
и родом окружения. Какое окружение получает утверждение, решает стиль автора.

Отрицательный результат легко принять за второстепенный, потому что он ничего не
«доказывает положительно». Но контрпример показывает, что условие главной теоремы
существенно, и без него читатель не знает, можно ли теорему усилить.

## Таблица канвы по строкам

Пример заполненной таблицы; он показывает степень краткости и формой не служит.

| Элемент | Содержание |
| --- | --- |
| Вопрос | Образуют ли корневые функции оператора $L$ базис в $L_2(0,1)$? |
| Пробел | Известные теоремы требуют постоянного старшего коэффициента |
| Идея | Замена переменной сводит задачу к возмущению самосопряжённого оператора |
| Объект и условия | Вещественный ограниченный коэффициент с условием (A) |
| Результаты | Базис Рисса при (A); полнота без (A); пример без базиса при (B) |
| Значимость | Постоянство коэффициента для базисности не нужно; условие (A) нельзя заменить на (B) |
| Границы | Знакопеременный коэффициент методу недоступен; размер скобок не оценён |

Типичные трудности:

- «Пробел» не заполняется одной фразой, когда история вопроса не разобрана: неясно,
  что именно не покрывают прежние работы.
- В строке «Идея» оказывается перечень средств. Идея — ход, без которого доказательство
  не складывается; остальное принадлежит технике.
- «Значимость» повторяет «Результаты». Тогда нет сравнения: строка должна говорить, что
  изменилось по отношению к известному.
- «Границы» пусты. У метода есть место, где он перестаёт работать; если оно не названо,
  читатель найдёт его сам и перестанет доверять остальному.
