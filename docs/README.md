# Документация

Документация отвечает на два вопроса; у каждого своя папка.

- **[howto/](howto/)** — как пользоваться набором: установить окружение, создать проект,
  вести тему от источников до статьи.
- **[concept/](concept/)** — как набор устроен: слои по назначению, границы шаблона,
  что переписывает обновление.

| Файл | Вопрос, на который отвечает |
|---|---|
| [howto/guide.md](howto/guide.md) | Как провести тему целиком: установка, создание проекта, постановка, команды, рецензия и формализация, статья |
| [concept/architecture.md](concept/architecture.md) | Как устроен сам набор: деление на слои по назначению, что копируется в проект целиком, что описывает и проверяет копирование |

Порядок чтения для нового читателя: guide → architecture. Возможности и таблицу состава
перечисляет [README.md](../README.md); правила проекта, которые читают агенты, —
[../template/AGENTS.md](../template/AGENTS.md); запуск DeepSeek Harness и перенос
воркфлоу Claude Code — [../template/DEEPSEEK.md](../template/DEEPSEEK.md).
